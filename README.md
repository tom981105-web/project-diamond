# PROJECT DIAMOND ⚾

독립적인 가상 야구선수 커리어 게임. 현재 **V1.3**.

- 선수 중심 홈과 하단5메뉴, 4단계 생성, 결산→진로→계약 흐름
- 첫/두 번째 훈련 과제, 저장되는 진로 선택과 실제 다음 시즌 효과
- 타자·선발·중간계투·마무리, 유형별 초기 능력 선택
- 고졸 프로 또는 대학3시즌36경기 → 평가·입단 구단 선택
- 프로144경기, 훈련·회복·부상·1군/2군, 시즌 계약과 가상 해외리그
- 순위·포스트시즌·수상·국제대회·라이벌·은퇴 기록
- 커리어10슬롯, 자동저장, JSON 백업·가져오기

[플레이](https://tom981105-web.github.io/project-diamond/) · [기능 검증/알려진 한계](docs/QA-2026-10-21.md)

모든 구단과 리그는 가상이며 한국·일본·미국 모두10구단144경기 간소 규칙을 사용합니다. 현실 FA/병역/리그 규칙의 완성형 시뮬레이션이 아닙니다. 게임 기록은 브라우저에 저장되므로 기기 변경 전 JSON 백업을 받으세요. 기존 저장의 과거 기록은 재계산하지 않습니다.

## 실행과 테스트

정적 서버: `python3 -m http.server 8765`.

회귀 테스트: `npm ci` → `npx playwright install --with-deps chromium` → `npm test`.
테스트는 서버를 자동 실행하며 격리된 브라우저로 진행합니다. CI에서도 동일 테스트를 실행합니다.

GitHub Pages는 main의 저장소 루트를 배포합니다. PR #5의 V0.9 원본은 병합하지 않았습니다. V1.3은 진로 선택을 현재 저장 구조와 계약 전환에 맞게 독립적으로 다시 구현했습니다. [UI/흐름 변경 및 검증](docs/UI-V1.3.md)을 참고하세요.
