# PROJECT DIAMOND ⚾

야구선수 커리어 시뮬레이션 웹게임. 현재 준비된 버전은 **V0.6**입니다.

## V0.6 기능
- 타자·투수 선수 생성 및 시즌 진행
- 가상 10구단 및 리그 순위
- 능력치 성장, 훈련, 부상, 승격/강등
- 계약, 트레이드, FA, 포스트시즌 및 개인상
- 한국·일본·미국 가상 리그 이동
- 국가대표, 가상 국제대회, 라이벌 및 업적
- 브라우저 자동 저장과 JSON 백업

## 웹 배포

V0.6 압축 파일의 `project-diamond/` **폴더 안에 있는 파일 8개 전체**를 저장소의 **최상위 경로**에 업로드해야 합니다. `index.html`과 `v2.js`, `v3.js`, `v4.js`, `v5.js`, `v51.js`, `v6.js`, `README.md`가 같은 폴더 깊이에 있어야 합니다.

업로드 후 GitHub 저장소 **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**로 설정하세요.

예상 웹주소: https://tom981105-web.github.io/project-diamond/

**주의:** 게임 기록은 각 브라우저에 저장됩니다. PC를 바꾸거나 사이트를 이전하기 전에 게임에서 JSON 백업을 내보내세요.

GitHub 저장소 초기 안내 문서 설정 완료. 실제 V0.6 게임 파일은 아직 업로드되지 않았습니다.
