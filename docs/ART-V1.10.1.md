# V1.10.1 — 사용자 제공 첫 아트 연결

첫 번째 첨부 `journey-01.png.png`는 첫 유니폼 장면, 두 번째 `avatar-01.png.png`는 첫 아바타다. 원본 업로드 파일은 유지하고, 웹 전송용 WebP(quality92)만 저장소에 추가했다. 그림 자체의 배경·내용·구도를 편집하지 않았다. 아바타의 알파 채널을 유지했다.

- `assets/journey/journey-01.webp`: 시작 화면 첫 유니폼 장면. 16:9 컨테이너와 contain으로 모자·글러브·신발을 자르지 않고 표시한다.
- `assets/portraits/avatar-01.webp`: 1번 선택 카드, 생성 미리보기, 해당 아바타를 선택한 선수의 홈·선수 프로필에 표시한다.
- 나머지 아바타/여정 단계는 기존 대체 표시를 유지한다. 기존 저장의 ui13.avatar 값을 바꾸지 않는다.
- 선택 카드에도 업로드 아바타를 반영하고, 미리보기에서 선택 카드 이미지를 복제하지 않고 원래 SVG만 대체 표시로 사용해 중복 이미지를 방지했다.
- 이미지 로딩 및 프로필 열람은 경기·성장·계약·저장 값을 변경하지 않는다.

기존64개 회귀와 실제 장면 로딩/비율/단계 전환 및 첫 아바타 선택→홈→선수→새로고침 검증2개를 실행한다. 파일을 받지 못했던 나머지 장면은 추정해 채우지 않는다.
