# V1.11 — 전체 아트 적용과 아바타 선택 UX

사용자 제공 made.zip의 11장을 확인했다. 원본 업로드/압축파일은 유지하고, 웹용 WebP(quality92)로 변환해 적용했다. 그림의 구도·내용·배경을 편집하지 않았다. 아바타5의 빛 번짐도 제공된 원본의 일부로 유지했다. 캐릭터 6장 모두 알파 채널이 있으며, 장면5장은1672×941이다.

| 경로 | 적용 위치 |

| assets/journey/journey-01~05.webp | 시작 화면 첫 유니폼/프로 데뷔/첫 안타/우승 도전/나의 기록 버튼 |

여정 장면은16:9 contain으로 보여준다. 선수의 생성 정보·성과를 대신하는 그림이 아니라 시작 화면의 예시 일러스트다. 아바타 index0~5의 기존 저장 번호를 유지한다. 새 아트는 저장된 외형 번호를 따라 교체되며 경기·성장·계약 수치를 바꾸지 않는다.

## UX

- PC는6개 한 줄, 모바일은3개씩 두 줄의 작은 카드로 정리해 선택 화면이 길어지지 않게 한다.
- 큰 미리보기 유지, 선택된 항목은 테두리·배경과 aria-pressed로 구분한다. 미선택 hover가 진한 주요 버튼색으로 바뀌던 CSS를 수정했다.
- 방향키는 실제 열 개수에 따라 이동, Home/End는 첫/마지막 아바타 선택. 포커스와 선택을 함께 이동한다.
- 같은 이미지를 반복 선택하면 이미 로드된 선택 카드/미리보기 DOM을 유지한다. 이미지 실패/미등록 시 기존 SVG 대체 표시를 유지한다.
- 이전 패치의 생성 진입·이전 단계 스크롤 초기화를 유지한다.

## 검증

기존67개와 신규3개:390/1366px에서 모든11개 아트의 실제 로딩·장면전환·선택·비율·그리드 높이/넘침, 키보드 이동·캐시 DOM 유지·6번 아바타 생성→홈→선수→새로고침 및 상태 전체 동일성. 이미지 누락 테스트는 실제로 해당 경로를 제거해 대체 표시를 검증하도록 갱신했다.

KICKRU 캡처와 비교해 한 번에 고르는 생성 화면, 선택 미리보기, 고정된 주요 행동과5개 탭의 동선을 개선한다. 원본 코드/캐릭터/로고는 사용하지 않고 사용자 제공 독자 야구 아트를 사용한다. 동일도 수치를 측정했다고 주장하지 않는다.
