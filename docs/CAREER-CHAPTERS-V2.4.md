# V2.4 — 육성 상담과 실제 성장, 시즌 반응, 결산

## 이번 패치

- 선수 생성의 마지막 단계에서 선택한 아바타·이름·포지션·진입 경로·두 훈련 과제를 카드로 확인합니다. 이전 단계로 돌아와 이름 등을 고쳐도 같은 선수 유형의 훈련 과제를 유지합니다. 타자/투수 유형이 바뀌면 해당 유형으로 새로 고릅니다.
- 시즌의 ‘나의 육성 방향’에서 코치 상담을 신청할 수 있습니다. 이야기 기능이 꺼져 있으면 버튼에 켜는 동작을 명시합니다. 기존 이야기·필수 선택·부상·확정 계획을 덮어쓰지 않으며, 훈련 7경기가 남지 않으면 상담을 차단합니다.
- 코치는 현재 두 과제를 유지하거나 두 가지 다른 과제 조합을 제안합니다. 변경 선택만으로 능력을 주지 않습니다. 실제 기본 focus/secondaryFocus를 바꾸고 일반 훈련 7팀 경기 계획을 확정합니다. 이후에도 기본 과제는 유지하며 기존 성장 계산을 사용합니다.
- 상담에서 고른 실제 능력과 당시 값으로 약속을 보관합니다. 28팀 경기 이상 지난 뒤 후속 점검에서 당시 값과 점검 시점의 실제 값을 비교합니다. 이 변화에는 그동안의 실제 훈련·출장 경험·시즌 전환 등 다른 성장 원인이 포함될 수 있습니다. 점검 화면을 열어 보상을 소급 지급하지 않습니다. 점검 뒤 약속을 마치고, 이적하면 기존 구단 약속을 초기화합니다.
- 실제 56팀 경기 이후 기록을 바탕으로 인터뷰 상황을 만날 수 있습니다. 선택의 신뢰·팀 유대·사기만 기존 계산에 반영하며 경기 성적을 바꾸지 않습니다.
- 시즌 중 반응 탭에서 현재 실제 성적·현재 과제에 맞춘 가상 코치 반응·최근 실제 선택을 확인합니다. 미진행 경기를 만들어 집계하지 않습니다.
- 시즌 결산은 ‘성적과 팀 / 실제 성장 / 이야기와 반응’ 세 항목으로 나눕니다. 키보드 화살표·Home·End로도 이동합니다. 조회·전환·닫기는 저장을 바꾸지 않고 기존 최종 확인만 다음 진로로 이어집니다. 지난 시즌 아카이브는 기존 통합 기록을 유지합니다.

## 일정과 저장

저장 키와 version:1을 유지합니다. 기존 세이브를 보는 것만으로 상담이나 인물, 과거 성장치를 생성하지 않습니다. 신규 선택에 한해 선택적 narrative22.history의 training과 thread.coach 스냅샷 등을 기록합니다. 이전의 미해결 이야기와 선택 기록은 계속 지원합니다. 손상된 추가 훈련 지시는 적용하지 않습니다.

자연 발생 이야기는 기존대로 최소 28팀 경기 간격, 시즌당 총 3개, 활성화 뒤 자동 정지 최대 두 번입니다. 사용자가 직접 여는 상담은 간격을 기다리지 않는 명시적 행동이며 같은 시즌 3개 이야기 중 하나를 사용합니다. 상담은 시즌당 한 번입니다. 상담을 직접 여는 행동은 자동 정지 횟수에 포함하지 않습니다. 이야기가 이미 세 개 제공됐거나 다른 선택이 기다리고 있으면 새 상담을 만들지 않습니다. 넘기기·알림 끄기도 기존 방식으로 작동합니다.

## 연출과 검증

외형은 사용자 제공 야구 캐릭터를 유지합니다. 상담 배경의 야구 다이아몬드·칠판·훈련 노트는 자체 HTML/SVG로 구성하며 새 외부 이미지를 요구하지 않습니다. 참고 게임의 원본 코드·고유 아트·문구는 사용하지 않습니다. 동일성 비율을 정밀 측정한 결과는 없습니다.

추가 검사는 생성 미리보기·뒤로 이동 보존, 타자/투수 실제 두 과제 훈련과 점검, 현 방향 유지 시 무보상, 확정 계획·재활·대기 선택·일정 부족 보호, 손상 훈련안 거부, 현재 성적 기반 반응, 실제 기록 기반 인터뷰, 320/390/1366px 상담·결산 조작과 저장 불변을 포함합니다. 기존 대학 36경기·프로·계약·부상·급여·아카이브·저장·불러오기 회귀 검사도 유지합니다.

## V2.4.1 화면 안내 보정

두 과제 제안에서 부가 효과가 없을 때 구분점이 겹치던 표시를 정리했습니다. 기본 훈련 버튼은 수비·송구 등 실제로 고른 과제를 훈련하므로 ‘선택 과제 훈련’으로 표시하고 두 과제를 모두 안내합니다. 기존 타격/투구 고정 제목이 실제 과제와 어긋나던 문제를 수정하며 성장 계산과 저장 데이터는 바꾸지 않습니다.
