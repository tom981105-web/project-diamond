# V1.7 — 상황 확인과 계약 확정

KICKRU 실전 조사 `01_KICKRU_기능분석.md`의 6절 전환점·7.2절 계약 모달에서 확인한 ‘상황을 살펴보고 선택’, ‘조건 검토 후 확정’ 흐름을 야구에 적용했다. 원본의 코드·자산·서명 그림·문구를 복제하지 않았다. 전자서명 그리기는 추가하지 않았다.

- 계약 비교 카드에는 핵심 조건과 상세 버튼을 둔다. 협상은 접힌 영역에서 열며 협상 결과/미해결 역제안이 있으면 펼친다.
- 계약 상세 창은 실제 제안의 연봉·기간·총액·역할과 현재 소속/연봉을 보여준다. ‘이 제안 선택’은 저장된 선택만 바꾸고 계약을 체결하거나 해를 넘기지 않는다.
- ‘진로 확정·다음 시즌’은 최종 조건과 육성 방향을 확인하는 창을 연다. 최종 확인만 기존 계약/성장/다음 시즌 함수를 실행한다. 미해결 역제안은 기존 규칙대로 먼저 처리해야 한다. 은퇴도 완료 시즌 수를 확인한 뒤 확정한다.
- 기존 계약 유지 화면은 잔여 기간과 합계를 표시하며 새 협상이 발생하는 것처럼 안내하지 않는다.
- 중요한 사건 카드의 ‘상황과 선택 자세히 보기’에서 실제 몸 상태, 소속 단계, 남은 요청 일정과 계획의 효과를 확인한다. 사건 창은 사용자가 열며 강제 팝업을 추가하지 않는다. 기존 직접 선택 버튼도 유지한다.
- ‘나중에 확인’, 닫기, Escape는 대기 사건이나 일정에 영향을 주지 않는다. 선택은 동일한 사건 ID를 확인한 뒤 기존 훈련/휴식/재활 계획만 확정하며, 경기 진행은 이어가기 행동으로 분리한다.

## 호환 및 상태 보호

저장 키와 version:1, 선수 기록과 계산식은 유지한다. 추가 영구 저장 필드는 없다. 창의 상태는 일시적이며 새로고침 후 다시 검토할 수 있다. 선수 객체나 연도가 바뀌면 열린 창을 닫는다. 최종 확인은 검토한 선수·연도·계약 조건·육성 방향이 일치할 때만 실행하며, 중복 확정으로 시즌이나 계약 이력을 두 번 만들지 않는다.

## 검증 범위

기존 39개 Playwright 회귀 테스트에 최종 확인 단계를 반영하고 5개 테스트를 추가했다. 계약 검토/취소/선택/저장 복원, 최종 확인 전후 실제 계약 조건 및 1회 적용, 부상 사건 보류와 재활·복귀·잔여 일정, 다른 선수 복원 시 창 폐쇄, 모바일 넘침과 키보드 Escape/포커스 복원을 검증한다. 기존 대학 36경기·프로 시즌·타자/투수·23시즌 은퇴·저장 오류 복원·실제 성장/부상/계약 검증을 유지한다.
