# V1.12 커리어 동선과 화면

74장 참고 화면에서 확인한 정보 계층과 단계별 진행 방식을 야구 커리어에 적용합니다. 원본 코드·이미지·기사·댓글은 사용하지 않습니다.

- 홈: 작은 선수 이미지, 현재 종합 능력과 기록된 기준 대비 변화, 통산 프로 기록, 확인할 일과 집중 육성. 지나온 시즌은 펼쳐서 조회합니다.
- 시즌: 대학 진행 → 대학 36경기 후 프로 입단, 프로 준비 → 중간 선택, 시즌 결산 → 육성 방향 → 계약 검토·최종 확정. 현재 단계의 설명과 이동 경로를 표시합니다.
- 부상·복귀 선택: 기존 계획을 저장한 결과를 보여주고, 경기와 회복 계산은 이어가기 이후 적용됨을 안내합니다.
- 육성 선택: 다음 시즌 최종 확정 시 한 번 적용된다는 점을 표시합니다. 방향 변경 시 다시 육성 단계로 돌아갑니다.
- 계약: 기존 조건 상세·협상·최종 확인을 사용합니다. 계약 서명 그림, 새 생활 이벤트, 상점, 경기 중계는 이번 패치 범위가 아닙니다.

## 저장과 계산

`career-flow.js`는 기존 상태와 DOM에서 현재 단계를 도출합니다. 새 저장 필드·키·무작위 추첨·계산 규칙을 추가하지 않습니다. 홈 이동과 조건 확인만으로 경기·연봉·능력치를 변경하지 않습니다. 현재 능력 변화는 기존 기록된 기준값과 비교하며 이전 버전의 누락 기록을 만들어 내지 않습니다.

## 검증

새 기능 회귀 검증: 홈 작업 이동 시 상태 불변, 결산→육성→계약→다음 시즌 효과 1회 적용 및 재접속, 중간 부상 선택과 남은 일정 보존, 대학 36경기→프로 입단 및 기록 보존, 390·800·1366px 화면. 기존 전체 테스트도 함께 실행합니다.
