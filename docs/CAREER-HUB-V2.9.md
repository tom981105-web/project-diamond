# V2.9 — 홈에서 경기 기록까지 이어지는 흐름

KICKRU 실전 분석의 홈·시즌·결과 연결 구조를 참고하고, 야구용 화면과 구단 표식을 자체 구현했습니다. 원본 코드·이미지·문구를 가져오지 않았습니다. 신규 이미지가 필요한 패치는 아닙니다.

홈의 선수 카드에 현재 준비 상태를 표시합니다. 은퇴, 대학 36경기, 부상, 확정한 7경기 계획, 기본 몸 상태를 구분합니다. 눌러 선수 화면의 실제 준비 장면을 확인할 수 있습니다. 홈의 최근 경기와 시즌의 최근 경기에서 같은 경기 결과 화면을 엽니다. 팀 점수 → 내 경기 기록 → 저장된 경기 다시보기 또는 시즌 복귀로 이어집니다.

## 기록 범위

- 현재 연도와 일치하는 리그, 현재 완료 경기와 일치하는 라운드, 현재 소속팀의 마지막 경기만 사용합니다. 대학·새 시즌 개막 전에는 프로 최근 경기를 만들지 않습니다.
- 팀 승패는 저장된 최종 점수를 내 소속팀 기준으로 비교합니다. 원정팀·홈팀 순서와 내 팀 강조를 유지합니다.
- 개인 성적은 같은 연도·같은 경기의 `career14.lastAppearance`와 해당 시즌 `recent`의 마지막 경기 증분을 읽습니다. 타자는 타수·안타·홈런·타점·볼넷·도루, 투수는 이닝·탈삼진·자책점·피안타·볼넷·승/세이브를 표시합니다. 시즌 누적과 구분합니다.
- 공식 출전이 없으면 회복 계획, 부상, 기용 경쟁/등판 휴식 등 기록된 사유를 표시하며 개인 성적 표는 만들지 않습니다. 이전 저장에 출전 메타데이터가 없다면 미보관 안내를 표시합니다.
- 선수·연도·경기가 바뀌면 열려 있던 결과 화면을 닫습니다. 결과 열람·닫기·다시보기·시즌 복귀는 저장, 난수, 경기·성장 계산을 호출하지 않습니다. 기존 키와 저장 형식은 그대로입니다.

## 검증

새 테스트 10개: 타자/투수 실제 엔진 경기 증분과 결과 표시 일치, 다시보기 후 저장 불변, 휴식/재활 결장, 선발투수 등판 휴식, 메타데이터 누락과 지난 시즌/선수 교체, 대학 준비, 320/390/1366px 결과 화면과 복귀 동선. 기존 화면 구성 6개와 함께 로컬 16개 통과. 전체 CI와 실배포 검증은 PR에 기록합니다.
