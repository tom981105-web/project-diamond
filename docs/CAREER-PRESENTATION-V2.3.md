# V2.3 — 시즌의 성적, 만나는 사람, 다음 선택

## 화면과 플레이

- 시즌 첫 카드에 타자 타율 / 투수 평균자책점, 실제 출장·안타·홈런 또는 등판·승리·탈삼진을 표시합니다. 기록이 없으면 비율은 —로 표시합니다. 대학 36경기 진행 표시는 유지합니다.
- 소속·포지션·기용 상태를 역할 카드에 정리했습니다. 훈련 상세는 펼쳐서 확인합니다.
- 활성화한 라커룸 이야기로 자동 시즌 진행이 멈추면 진행 창을 닫고 해당 이야기의 선택 창을 바로 엽니다. 닫기·뒤로 가기·다시 불러오기는 선택을 적용하지 않으며, 매번 자동으로 다시 열지 않습니다. 필수 부상·기용 선택을 우선합니다.
- 보유한 독자 제작 여정 그림과 가상 동료·코치·후배의 대화를 이야기 창에 사용합니다. 구단별 가상 이름은 난수를 소비하지 않는 결정적 방식으로 정합니다. 새 이야기에는 등장인물을 함께 저장하고, 결산과 지난 시즌에도 당시 인물을 표시합니다.
- 선수의 ‘함께 뛰는 사람들’에서 구단 신뢰, 팀 전체 유대, 이어지는 약속, 최근 12번 만남의 선택과 실제 효과를 확인합니다. 개인별 추가 호감도나 별도 보상은 도입하지 않았습니다. 수치는 기존 실제 계산에 쓰는 값입니다.
- 계약 제안은 자체 제작 구단 마크와 연봉·기간·역할을 간결하게 표시합니다. 조건 상세·협상·서명은 기존 계산을 사용합니다.
- 홈의 훈련 안내 아이콘과 팬 반응의 어색한 조사도 수정했습니다.

## 저장과 계산

저장 키·저장 버전·기존 능력·계약·과거 기록을 변경하지 않습니다. 화면 조회와 이동만으로 등장인물이나 선택을 생성하지 않습니다. 새 사건을 실제로 제공할 때 선택적 speaker 필드를 기록하며, 과거 익명 이야기는 이름을 소급해서 채우지 않습니다. 선택 적용 시 기존 단일 보상 경로와 계획 확정 조건을 그대로 사용합니다. 부상 기간·성적·능력을 조회만으로 수정하지 않습니다.

## 검증 범위

기존 대학·프로·저장·계약·부상·이야기 회귀 테스트에 더해, 실제 타자/투수 성적과 화면 일치, 이야기 자동 표시 후 닫기·재접속, 등장인물과 관계 이력 보존, 익명 과거 데이터 보존, 계약 선택과 실제 제안 불변, 320/390/1366px에서 장면·선택·관계 이력의 조작을 검사합니다. 화면 구성 기존 검사는 320/390/800/1366px를 포함합니다.

KICKRU는 일반적인 화면 흐름과 정보 우선순위의 참고로만 사용했습니다. 원본 코드·문구·고유 이미지·로고를 사용하지 않았으며 동일성 비율을 측정한 결과는 없습니다.
