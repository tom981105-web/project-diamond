# V1.10 — 카드형 커리어 UI와 탐색 동선

사용자 요청에 따라 KICKRU 실전 캡처의 화면 밀도와 상호작용 구성을 다시 비교했다. `kickru-22-weakfoot-progress.jpg`의 선수 요약/능력치 카드, `kickru-01-first-season.jpg` 및 `kickru-07-aging.jpg`의 결산, `kickru-11-league-table.jpg`의 표 구성을 기준으로 삼았다. 실제 서비스의 시작 화면과 생성 1·2단계도 브라우저에서 다시 확인했다. 원본 소스·캐릭터·이미지·문구는 가져오지 않았다. 동일도 수치는 측정하지 않았다.

## 화면 변화

| 대상 | 변경 |
| --- | --- |
| 공통 | 최대 800px 앱 영역, 회색 바탕과 흰 카드, 짧은 화면 제목, 파란 주요 행동, 하단 5개 메뉴와 활성 상태 |
| 홈 | 가로 프로필, 통산/종합/나이/시즌 정보, 다음 행동 카드, 실제 화면으로 이동하는 리그·선수·기록 바로가기 |
| 선수 | 소속/포지션/OVR/집중 육성 요약 → 6개 능력치 → 훈련·몸 상태 → 상세 기용 평가. 집중 항목만 파란 막대, 기준값이 있는 변화만 표시 |
| 시즌 | 진행/훈련/결정/성적을 카드로 분리. 기존 결산 → 육성 → 계약 흐름과 실제 144경기 계산 유지 |
| 기록·소식 | 카드와 탭, 시즌별 목록 및 비교표, 기존 기록과 연결된 소식 유지 |
| 생성 | 선택한 아바타 큰 미리보기, 4단계 진행 표시와 하단 주요 행동, 선택 상태 접근성 보완 |
| 시작 | 5개 야구 여정 선택과 장면 자리. 다른 사용자 순위/가짜 랭킹을 만들지 않음 |

`career-ui.js`는 마지막 표시 계층이며 저장, 경기, 성장, 계약 함수를 호출하거나 난수를 소비하지 않는다. `career-ui.css`에서 화면을 구성한다. 기존 엔진 필드·저장 키·JSON 형식을 바꾸지 않는다. 상세 기용 평가를 접어 화면을 줄였으며 펼치면 모든 기존 설명을 볼 수 있다. 대학의 홈 바로가기는 프로 순위 대신 대학 시즌으로 이동한다.

## 추후 이미지 교체

`visual-assets.js`에 로컬 파일 경로를 넣는다. 이미지가 없거나 로딩에 실패하면 직접 작성한 기존 야구 SVG/야구장 표시가 남는다. 이미지의 유무는 선수 수치나 저장에 영향을 주지 않는다.

- `portraits`: 아바타 선택 순서의 6개 이미지. 투명 PNG 또는 WebP, 권장 512 × 640px(세로), 캐릭터 전체를 가운데/하단에 배치. 홈과 선수 프로필, 생성 미리보기에서 사용한다. 현재 선택 버튼은 기존 6개 SVG를 사용한다.
- `milestones`: 첫 유니폼/프로 데뷔/첫 안타/우승 도전/나의 기록 5개 장면. 권장 1600 × 900px. 문구와 버튼은 HTML이 담당하므로 이미지에 글씨를 넣지 않는다.
- 원본 게임 아바타·로고를 재사용하지 않고 별도로 준비한 야구 이미지를 사용한다.

## 검증 범위

기존 회귀 58개와 UI 검증 6개. 홈 바로가기와 5개 탭, 반복 이동 시 능력치 증감 중복 방지, 열람 전후 커리어 전체 동일성, 새로고침 복원, 390/800/1366px 오버플로 및 하단 메뉴, 투수/대학 정보 구분, 아바타 선택 미리보기, 이미지 성공·실패·미등록 시 대체 표시를 검증한다. 기존 코치 패널 검증은 접기 항목을 먼저 펼치는 동작으로 갱신했다.
