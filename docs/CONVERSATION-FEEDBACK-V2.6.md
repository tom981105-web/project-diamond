# V2.6 — 선택하는 선수와 실제 선택 결과

기존 캐릭터를 대화의 선택 영역에 표시하고 선택지에 순서를 붙였습니다. 상대의 발언, 나의 선수, 선택지가 구분됩니다. 기존 장면과 캐릭터는 그대로 사용하며 원본 게임의 이미지·코드·대사를 가져오지 않습니다.

선택 처리 후에는 시즌 화면의 결과 카드로 초점을 옮깁니다. 실제 저장된 narrative22.history의 선택 문구와 적용 결과를 보여 주며, ‘선택 결과 다시 보기’로 같은 내용을 다시 읽습니다. 넘긴 이야기는 효과 없이 넘겼다는 결과를 표시합니다. 결과를 읽는 동작은 선택을 실행하거나 저장·성장·무작위 계산을 호출하지 않습니다.

결과 카드는 동일 선수·연도·구단·경기 시점의 마지막 선택만 표시합니다. 다음 경기를 진행하거나 새 사건이 오면 즉시 결과 카드는 숨겨지고 기존 선택 기록과 관계 화면에서 지난 선택을 계속 확인할 수 있습니다. 선수 교체·필수 사건·시점 변경 시 열려 있던 결과 창도 닫습니다. 저장 키·버전·구조는 변경하지 않습니다.

대화와 화면 진입에는 짧은 투명도 전환만 사용하고 모션 감소 설정에서는 적용하지 않습니다. 모달 자체를 이동하지 않아 하단 시트가 화면 밖으로 벗어나지 않도록 했습니다.

검증 범위: 기존 상담·성장·이야기·일정 보호, 320/390/1366px 결과 열람·키보드 닫기·저장 복원, 반복 열람 시 저장/난수 불변, 넘기기 무보상, 선수 교체 시 이전 결과 닫기. 실행 결과는 PR에 기록합니다.
