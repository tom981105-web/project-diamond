# V3.5 선수 생성과 경기 중계

선수 유형을 고르고 능력치 분포를 확인한 뒤 성장 과제를 정하는 흐름, 점수판과 구장 아래에 중계가 쌓이는 흐름을 야구에 맞게 정리했습니다. 기존에 제공된 원본 야구 아바타를 사용하고 구장은 독립 SVG로 그렸습니다. 원작 코드와 이미지는 사용하지 않습니다. 유사도 수치는 측정하지 않았습니다.

## 구현

- 4단계 생성 진행도를 접근성 속성으로 표시합니다. 선택한 스타일만 6개 실제 시작 능력치를 펼칩니다. 선택, 뒤로 이동, 재선택, 최초 생성의 기존 동작을 유지합니다.
- 아바타 미리보기·선택 카드·이름/진로/훈련 입력·고정 하단 확인 버튼의 크기와 간격을 정리했습니다. 생성 단계의 이름 오류는 다음 단계로 넘어갈 때 해제합니다.
- 다시보기는 기존 `league.last.frames[].plays`를 사용합니다. 이전 타석, 다음 내 타석/투구, 결과 보기와 역방향 이동을 지원합니다.
- 현재 이닝 점수는 재생한 타석까지만 표시합니다. 아직 시작하지 않은 홈 공격은 `—`로 표시하고, 종료 시 보관된 최종 점수를 표시합니다. 이닝 표는 펼쳐서 봅니다.
- 타석/안타/홈런 또는 상대 타석/탈삼진/볼넷은 재생한 구간까지만 집계합니다. 시즌 성적과 구분합니다. 최근 4개 타석을 역순으로 표시합니다.
- 타석별 기록이 없는 예전 경기에는 최종 점수와 안내를 표시하고 재생 조작을 비활성화합니다.
- 중계 하단 버튼은 스크롤 본문 밖에 배치해 작은 화면에서도 조작할 수 있게 했습니다.
- 시즌 진행 중 종합 능력과 안타/홈런 또는 탈삼진/승리를 실제 현재 성적에서 표시합니다.

## 저장과 계산

저장 스키마, 저장 키, 선수 생성 시 적용되는 능력치 합계 240, 훈련 주기, 경기 계산 및 난수 흐름을 변경하지 않습니다. 중계 이동 인덱스는 메모리에만 존재합니다. 다시보기는 저장·경기 진행·난수 호출을 하지 않습니다. 슬롯을 바꾸면 기존 중계를 닫는 동작을 유지합니다.

## 검증

새 테스트 7개: 320/390/800px 생성 선택과 대학 진로·훈련 과제 보존, 타자/투수 중계의 저장 원문 및 난수 호출 불변, 예전 점수 전용 경기, 현재 이닝의 미래 득점 차단. 기존 대학 36경기·프로 시즌·재생·계약·슬롯·진행 중단/재개 회귀 테스트도 실행합니다. CI 및 배포 후 실제 브라우저 확인 결과는 PR에 기록합니다.
