# V1.4 — 출전 경쟁과 선수 생활

KICKRU 조사 F06/F07/F09/F11/F12/F14/F20, D01/D04를 야구에 맞춰 독립 구현한다. 원작의 내부 확률·표현을 복제하거나 일치율을 주장하지 않는다.

## 연결된 계산

- 기용 평가 = OVR×0.45 + 감독 신뢰×0.35 + 컨디션×0.20 − 피로×0.15 + 최근 성적 보정(−8~+8). 최근 12팀 경기 타자 12타수/투수 3이닝 이상의 표본을 사용한다.
- 7팀 경기마다 평가. 경쟁 우위 진입 62, 유지 54 이상. 경기 기용 기회는 경쟁 중 28~68%, 우위 82~98%. 투수는 기존 5팀 경기 선발 간격/구원 등판 판정을 추가로 거친다.
- 야수의 수비 능력은 자신이 출전한 경기의 상대 인플레이 안타 확률에 작은 보정을 준다(개인 수비를 팀 수비 일부로 환산). 투수의 변화구는 투구 퀄리티에 반영된다.
- 몸 상태는 실제 타격 능력과 투수 퀄리티에 75~102.5%를 적용한다. 영구 능력치를 깎아 저장하지 않는다.
- 2군 신뢰는 실제 훈련 평가로 회복한다. 일반 +3/강훈련 +4/휴식 +1(7팀 경기 평가 시점), 부상 중 제외. 신뢰48·컨디션45 이상이면 복귀한다. 2군에서 프로 기록을 생성하지 않는다.
- 7팀 경기 계획: 타격/투구, 수비/변화구, 휴식, 부상 재활. 계획은 끝까지 잠기며 확정만으로 수치를 지급하지 않는다. 미선택은 기존 훈련 설정을 따른다. 휴식 계획은 공식 출전도 쉬는 완전 휴식이다.
- 12팀 경기 구간 중 실제 훈련6일 이상이면 +1, 그중 강훈련6일 이상이면 +2. 실전 경험은 타자24출장/투수24이닝마다 +1. 32세 이하·잠재력 상한, 실제 증가분만 원장에 기록한다.
- 부상·재활 완료·1/2군 이동·기용 역할 변경은 팀 경기 한 라운드를 마친 뒤 멈춘다. 사건ID·남은 요청 경기·선택을 저장한다. 확인 후 자동 진행하지 않으며 이어가기 버튼으로 남은 경기를 요청한다.
- 이전 버전의 현재/과거 성적을 재계산하지 않는다. `career14`는 선택 확장 필드다. 최초 로드 시 이전 출장에 경험 성장분을 소급 지급하지 않는다. 팀 경기 수와 선수 출장 수를 구분한다.

## 현재 범위

프로 출전 경쟁을 대상으로 한다. 대학36경기·스카우팅 경로는 기존대로 유지한다. 2군 경기는 별도 박스스코어 대신 훈련 평가로 모델링한다. 타자 기용은 경기 전체 출전/결장 단위이며 대타·수비 교체는 후속 범위다. 선발 휴식과 구원 승패·세이브는 기존 간소 엔진을 사용한다. 계획 기간은 달력상 일주일 대신 **7팀 경기**다.

계약 자격·다년 계약·이적 협상·국제대회·병역은 이번 패치의 개편 범위에 포함하지 않는다. 기존 기능의 존재를 실전 규정의 완전 구현으로 간주하지 않는다.

## 검증

기존20개 회귀 테스트에 휴식/저장·건강의 경기효과·기용차이·강등/훈련/콜업·부상중단/재활/복귀·상한/성장원장·구버전/슬롯격리 테스트7개를 추가한다. 실제 브라우저로 배포 후 선수 상태·7경기 계획·중간 사건·다음 시즌을 확인한다.
