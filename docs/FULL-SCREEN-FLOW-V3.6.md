# V3.6 전체 화면 플레이 흐름

## 범위

경기 다시보기·시즌 진행·현재/보관 시즌 결산을 800px 이하, 화면 전체 높이의 페이지 형태로 정리했습니다. 대화상자의 키보드 포커스·Escape·원래 화면 복귀 동작은 유지합니다. 바깥 화면은 불투명한 배경으로 가리고, 흰 본문과 고정 하단 동작을 공통으로 사용합니다. 휴대폰에서도 같은 구조입니다.

선수 생성에서는 중복된 상단 헤더를 숨기고 뒤로 가기·단계 표시부터 시작합니다. 제목을 두 줄로 정리하고 본문·능력치·결산 수치와 중계 문장의 크기와 간격을 조정했습니다. 원본 야구 캐릭터와 독립 구현한 구장을 유지합니다.

## 연결된 흐름

1. 최근 경기/지난 시즌 기록 → 준비 화면. 아직 재생하지 않은 점수와 개인 기록을 먼저 보여주지 않습니다.
2. 자동 중계 또는 타석별 보기 선택. 자동 중계는 1×/2×/4× 속도·일시정지를 지원합니다.
3. 이전 타석·내 타석/투구로 이동하면 자동 재생을 멈춥니다. 구간 점수와 개인 기록은 저장된 타석만 집계합니다.
4. 종료 → 실제 최종 점수·처음부터 보기·원래 화면 복귀. 현재 마지막 정규시즌 경기이면 시즌 결산으로 이어집니다.
5. 결산 확인 시에만 기존 ‘검토 완료’를 저장하고, 육성 방향·계약 선택으로 이어집니다. 결산을 열거나 닫는 것만으로는 저장하지 않습니다.

## 저장·계산 보호

새 필드나 저장 키를 추가하지 않습니다. 경기 준비·재생 인덱스·재생 속도·일시정지는 메모리에만 있습니다. 경기·성장·부상·훈련·계약 엔진 및 난수 호출은 변경하지 않습니다.

자동 중계의 키보드 포커스를 다음 프레임에도 유지합니다. 속도 선택에 집중하면 재생을 일시정지해 항목을 안정적으로 고를 수 있습니다.

자동 중계는 닫기, Escape, 선수 교체, 연도 변경, 페이지 이탈, 탭 숨김에서 중단합니다. 점수 전용 예전 경기에는 재생 기능을 활성화하지 않습니다. 다시 열면 준비 화면에서 시작합니다.

## 검증과 비교 기준

추가한 8개 테스트는 320/390/800/1366px 전체 높이·하단 버튼, 준비→수동/자동 재생, 속도·일시정지, 닫기/선수 교체/이탈, 실제 종료 결과, 결산 연결, 저장 원문과 난수 불변을 검사합니다. 기존 중계 테스트는 새 준비 단계를 통과한 후 동일한 기록 검증을 수행합니다.

시각 비교는 같은 832×940px 및 390×640px에서 생성·준비·중계·결과·결산의 상단 위치, 폭, 본문 밀도, 하단 조작을 확인합니다. 기능 테스트 수를 시각적 유사도 수치로 환산하지 않으며 ‘90% 달성’처럼 측정하지 않은 수치를 보고하지 않습니다. CI·실제 배포 결과는 PR에 기록합니다.
