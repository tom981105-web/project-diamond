# V2.0 통합 커리어 개편

참고 화면의 정보 계층과 커리어 흐름을 야구에 맞춰 독립 구현합니다. 원본 이미지·문구·코드는 사용하지 않습니다. 선수 생성부터 은퇴까지 같은 저장 기록을 화면별로 연결합니다.

## 이번 업데이트

- 생성: 선택한 신인 유형의 6개 실제 시작 능력을 막대로 펼칩니다. 기존 능력 합계 240 규칙 유지.
- 계약: 조건 상세 → 최종 확인 → 손그림 또는 선수 이름으로 서명 → 실제 다음 시즌 적용. 서명은 게임 확인이며 잉크 이미지나 개인정보를 서버에 보내지 않습니다. 계약 이력에 이름·방식만 보관합니다.
- 입단·재계약: 현재 계약의 팀·연봉·기간과 새 출발 장면을 홈에서 확인합니다.
- 결산·반응: 실제 성적·수상·생활 선택을 결산과 가상 기사·팬 반응에 함께 표시합니다. 완료한 시즌과 아카이브가 같은 사실을 사용합니다. 이전 저장의 없는 생활 사건은 재구성하지 않습니다.
- 생활 선택: 시즌마다 한 번, 회복·팀 적응·베테랑 역할을 선택합니다. 효과는 현재 컨디션·피로·구단 신뢰·사기·팀 유대에 즉시 반영됩니다. 부상 중의 공식 재활 선택은 기존 시스템이 우선합니다.
- 장기 훈련: 세 프로젝트 중 하나. 실제 비부상·비휴식 훈련일만 36일 누적하며 시즌을 넘어 이어갑니다. 12일마다 해당 능력 +1, 총 최대 +3. 32세 이하·잠재력/99 상한. 한 시즌에 프로젝트 시작은 한 번입니다.
- 소비: 새로 완료한 프로 시즌에 연봉을 한 번 정산합니다. 과거 연봉은 소급 적립하지 않습니다. 3,000/6,000/10,000만원 상품으로 실제 능력 +1, 시즌당 구매 한 번. 잔액·상한·중복 구매를 검사합니다.
- 기록: 프로 팀·시즌 필터, 실제 대학 경기·연도 필터, 대표팀 선발/메달 기록을 분리합니다. 프로 진행 중 성적은 완료한 시즌과 중복 집계하지 않습니다. 대학의 미보관 볼넷/OPS와 대표팀 개인 성적은 만들지 않습니다.
- 경기 다시보기: 실제 계산 중 타석 결과·득점·주자·아웃·이닝 점수를 보관하고 구장/점수판에서 열람합니다. 다음 타석·결과만 보기 모두 재계산하지 않습니다. 현재 경기와 새 시즌 보관함에서 접근합니다. 포스트시즌 결정전의 새 경기 계산이나 수동 타격 조작은 이번 구현에 포함하지 않습니다.
- 은퇴: 사용자 제공 장면, 완료한 시즌 수·통산 기록·최고 종합 능력 시즌과 기록 조회 경로를 제공합니다.

## 계산 연결

`career-weeks.js`의 실제 경기 완료 지점에서 `DiamondLife.afterGame`를 호출합니다. 프로젝트 누적은 연도/팀 경기 키로 중복 적용을 차단합니다. 사기·팀 유대 보정은 `(사기 + 팀 유대) × 0.05%`, 범위 -1%~+2%이며 기존 경기 능력 계수에 곱합니다. 선택하지 않은 이전 커리어는 보정 1을 사용합니다. 실제 소속이 바뀌면 팀 유대는 절반으로 조정하며 보유 자금과 장기 훈련은 유지합니다.

`v2.js`에서 추가한 `frames/plays`는 이미 계산한 결과를 기록할 뿐 난수를 추가하지 않습니다. `review19.match20`에 마지막 경기만 보관합니다. 이전 경기의 타석별 기록이 없으면 최종 점수와 미보관 안내만 표시합니다. 선수 결장 경기에도 결과를 임의 생성하지 않습니다.

## 저장 보호

기존 version:1, 저장 키, 10개 슬롯과 JSON/IndexedDB 저장을 유지합니다. 선택적 `life20`은 생활/프로젝트/구매 선택 또는 새 시즌 급여 정산 때만 생성합니다. 열람만으로 이전 선수의 능력·통산 기록·연봉·나이를 바꾸지 않습니다. 새 서명은 계약 확정 성공 후 해당 계약 이력에 한 번 붙입니다. 잉크 그림은 저장하지 않습니다.
