# V2.7 — 실제 준비 상태에 따른 선수 장면

기존 사용자가 제공한 캐릭터에 자체 SVG 구장·실내 훈련 배경을 조합했습니다. 시즌 제목 옆 ‘지금의 나’, 선수 화면의 준비 상태 버튼, 시즌 진행 화면에서 볼 수 있습니다. 이미지를 새로 만들거나 원본 게임의 자산을 가져오지 않습니다.

상태 우선순위는 은퇴 → 부상 → 확정한 휴식/재활 → 대학 → 확정한 훈련 → 2군 → 타자/투수의 다음 기회 준비 순서입니다. 휴식과 훈련의 남은 기간은 현재 경기와 실제 계획 종료 경기의 차이입니다. 마지막 출전 설명은 같은 연도·현재 경기의 lastAppearance가 있을 때만 표시합니다. 준비 장면은 경기의 타석/투구를 재현하지 않으며 출전을 보장하지 않습니다.

정상적인 준비 장면에는 2px 범위의 작은 움직임을 사용하고 회복·재활에는 움직임을 사용하지 않습니다. 모션 감소 설정에서도 정지합니다. 선수 교체 시 열려 있던 장면을 닫습니다.

새 모듈은 상태를 읽어 DOM만 구성합니다. 저장·난수·경기 계산·훈련 결과를 호출하거나 변경하지 않습니다. 기존 저장 키·버전·형식을 유지합니다. 시즌 진행에 추가한 장면은 스크롤 영역 안에 있어 중지 버튼을 밀어내지 않습니다.

로컬 검증: 기존 화면·일정 진행 19개 및 새 장면 상태 우선순위, 320/390/1366px, 대학/은퇴, 지난 출전 정보 제외, 선수 교체, 모션 감소, 저장/난수 불변 6개 검사 통과. 전체 CI 및 배포 검증은 PR에 기록합니다.
