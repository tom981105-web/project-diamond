# V3.3 선수와 훈련 계획

## 화면

- 기존 캐릭터로 선수 프로필·종합 능력·집중 과제를 정리합니다.
- 6개 능력 막대와 숫자를 강조합니다. 변화량은 기존 저장된 시즌 기준과 비교하며, 기준이 없으면 변화량을 만들지 않습니다.
- 선수 화면의 ‘훈련·휴식 계획 선택’과 시즌 화면 훈련·휴식 계획의 ‘효과를 비교하며 계획 선택’에서 동일한 비교창을 엽니다.
- 집중 과제 훈련·수비(투수는 변화구) 집중·휴식·재활을 비교하고 확정합니다. 선택 미리보기나 닫기는 저장하지 않습니다.
- 확정한 계획의 남은 경기와 실제 시즌 진행·구간 변화로 이동하는 경로를 제공합니다. 기존 집중 분야·강도 설정과 빠른 계획 선택은 유지합니다.

## 계산 연결

새 비교창의 확정은 `DiamondCareer14.choosePlan`을 통해 기존 엔진의 동일한 계획 확정 함수를 사용합니다. 새 성장·회복 계산을 추가하지 않습니다. 확정만으로 경기·능력·피로가 바뀌지 않으며, 실제 진행에서 반영됩니다.

회복 계획은 부상이 없을 때 매 팀 경기 컨디션 +3·피로 −5입니다. 부상 중에는 기존 재활 처리가 우선하여 컨디션 +2·피로 −3, 부상 기간이 줄어듭니다. 능력 성장은 12팀 경기 구간의 실제 훈련 6일 이상 조건, 강훈련 일수, 잠재력 상한과 32세 이하 조건을 안내합니다. 경기 기용·실전 경험·피로·주기 보정·다른 사건이 함께 적용되므로 7경기 성장량을 보장하지 않습니다.

기존 계획 진행 중 또는 커리어 선택 대기 중에는 새 계획을 확정할 수 없습니다. 부상 없이 재활은 확정할 수 없습니다. 대학·은퇴·시즌 종료에는 새 프로 계획 카드를 표시하지 않습니다. 시즌 끝까지 7경기 미만이면 남은 팀 경기만 확정합니다. 커리어·연도·경기 변경 시 열린 비교창은 만료됩니다.

## 저장 보호 및 검증

저장 키·형식·마이그레이션은 변경하지 않습니다. 화면 미리보기는 상태·저장 원문·난수를 변경하지 않습니다. 기존 엔진 API에는 원래 계획 함수를 노출하는 항목만 추가했습니다.

`tests/player-training.spec.js`는 320·390·800·1366px 비교창과 키보드 닫기·초점 복귀, 미리보기 저장 불변, 휴식 확정 전후와 실제 7경기 회복, 투수 변화구 강훈련의 실제 성장 기록, 부상·선택 대기·대학·종료·시즌 마지막 구간·33세·커리어 교체를 검증합니다. 기존 생성→대학→프로→계약·저장 회귀 검사도 함께 실행합니다.
