# V1.2.1 커리어 흐름 안정성 점검

기준 main: `c5780c79662d2ba4d02199aae17169f78bbaa067`.
첨부 인수인계서와 KICKRU 조사 00~08, 통합보고서, 관찰 JSON 및 증거 색인을 검토했다. 조사 범위는 ST26/GK8/CB11 총45시즌이다. 직접 관찰과 추론/설계 제안을 구분하며, 원작의 코드·고유 디자인·문구는 사용하지 않았다. 대학 3년×12경기는 기존 PROJECT DIAMOND 가상 규칙이며 KICKRU 대학4년을 그대로 복제한 규칙이 아니다.

## 재현 및 수정

- 운영 V1.2에서 대학 진학 선택 후에도 프로 1경기가 진행됐다. `v12.js` 초기 상태 생성이 리터럴 `\n`을 포함한 한 줄 주석에 묻혀 있었다. 신규 대학 커리어만 정상 초기화하고 이전 프로 커리어는 되감지 않는다.
- 대학 경계 12경기에서 '이번 시즌 끝까지'가 0경기를 요청했다. 다음 학년 진행을 허용하고 경기 시 연도·나이를 갱신한다. 생성 즉시 대학 성장/가상 기록을 주던 처리를 제거하고 실제36경기 후 평가·성장·입단 팀/연봉/드래프트 이력을 연결했다.
- 대학 중 프로 버튼을 숨기고 JSON 백업/가져오기와 슬롯 전환을 노출한다. 대학 성적은 프로 `current`/`career`에 합산하지 않는다.
- 슬롯 패널 삽입에 따라 화면을 자식 순번으로 분류하던 탭이 어긋났다. 실제 통계/소식 요소로 분류하고 슬롯 패널은 공통 위치로 이동했다.
- 복원 중 쓰기 및 생성 경쟁을 막고, 오래된 보조 백업보다 유효한 최신 localStorage를 우선한다. 슬롯ID/스냅샷/시각을 갖는 복구 저널과 실패 시 전환 중단을 추가했다. 공간 부족 시 IndexedDB 슬롯 복원을 확인한다.
- 시즌 종료 render가 만든 해외 제안이 최종 결산의 국내 제안3개에 덮였다. 결산 최초 확정 시 해외 포함4개 제안을 확정하고 재조회 시 재추첨하지 않는다.
- 기본 단타 진루가 한 베이스 과도하게 이동했다(단타3개에1득점). 인덱스를 수정했다. 희생플라이 타수 제외 조건과 만루 볼넷 타점도 수정했다.
- 홈/원정 투수의 능력치가 적용되는 이닝과 기록되는 이닝이 달랐다. 같은 등판 조건과 구위 계산을 사용한다. 구원투수는 간소 규칙상9회1이닝, 선발은 최대6이닝이다. 실제 투구아웃이 있을 때만 등판을 기록하고 승리/세이브 중복을 막았다.
- 은퇴 직전에 새 계약/팀 변경이 먼저 적용되던 경로를 차단했다. 현재의40세 자동 은퇴 규칙 자체는 유지한다.

## 호출 경로

스크립트 순서: index → v2 → v3 → v4 → v5 → v51 → v6 → v61 → v62 → v7 → v8 → progression-fix → v10 → v11 → v12 → setup.

생성 submit 리스너는 기본 생성 → 유형 적용(v8) → 아마 경로(v10) → 신규 대학 초기화(v12) 순서다. 대학 `play`는 `playCollege`로, 프로는 `managedPlay → v3Play → gameMatch → halfInning → atBat`로 이어진다. 프로144경기 후 `v4Finish`와 `v6Finish`가 확정된다. `nextSeason`은 은퇴 가드 → v6/v51/v5/v4/v3/v2/기본 전환을 거친다. render는 각 버전 래퍼를 역순으로 호출하고 일부 옛 래퍼에 여전히 초기화·저장 부작용이 있다. 저장은 v7 슬롯 큐와 v62 localStorage/보조 IndexedDB를 함께 사용한다.

## 검증 방법

`npm ci`, `npx playwright install --with-deps chromium`, `npm test`.
로컬은 Playwright + Chromium으로 실행했다. `CHROMIUM_PATH`는 이미 설치된 대체 Chromium 실행파일을 지정하는 선택사항이다. GitHub Actions는 표준 Playwright Chromium을 설치한다. 테스트는 매번 격리된 브라우저 저장소를 사용한다. 실제 이용자의 저장소를 삭제하거나 수정하지 않았다.

검증 내용은 tests/career.spec.js 및 tests/engine.spec.js에 재현 가능하게 기록했다. 타자/투수 대학1·4·12·24·36경기,3개 입단 제안 중2번째 수락, 프로1·7·144경기, 해외이적·연봉·다음연도, 훈련 성장·피로·컨디션 변화, 강제 부상 fixture의 결장·재활, 슬롯2개/전환/복원/삭제/재생성, JSON 백업/가져오기, 이전 대학경로 프로 저장 유지, 저장 공간 부족, 오래된 백업 마이그레이션,23시즌 은퇴, 주자/타점/희생플라이와 SP/RP/CL 홈원정 투구 계산을 포함한다. 인위적 실패·부상·저널 상태는 테스트 fixture이며 자연발생 전체 확률을 검증했다는 뜻은 아니다.
