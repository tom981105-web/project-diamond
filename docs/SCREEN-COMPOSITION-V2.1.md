# V2.1 화면 구성 개편

사용자가 제공한 참고 화면의 정보 우선순위를 분석하고 야구 데이터와 기존 캐릭터로 독립 구현합니다. 원본 코드·이미지·고유 문구를 복제하지 않습니다. 유사도를 숫자로 산정하지 않습니다.

- 홈: 선수 요약 → 확인할 일 → 입단/계약 안내 → 소비 → 탐색 순서. 진행 버튼은 작은 보조 동선으로 낮추고, 세 바로가기를 한 줄로 배치합니다. 시작 화면에서 주요 할 일이 먼저 보입니다.
- 시즌: 현재 챕터 안에서 실제 진행률·출장·타율/평균자책점·홈런/탈삼진을 표시합니다. 기존 중복 진행률 카드는 숨깁니다. 대학은 실제 36경기 진행만 표시하고 프로 성적을 섞지 않습니다. 훈련과 진행 버튼을 생활 이야기보다 먼저 배치합니다.
- 선수: 요약과 능력 막대의 밀도를 높이고 해외 리그 설명을 접어 둡니다. 훈련 선택·실제 몸 상태·계약은 그대로 접근할 수 있습니다.
- 계약: 실제 제안의 금액·기간·역할을 우선 표시하고 시장 평가 규칙은 펼쳐 볼 수 있습니다. 모바일 선택/계약 창은 하단에 붙고, 서명·확정 기능은 기존 실제 명령을 사용합니다.
- 결산: 기록과 성장의 행 간격을 정리하고 실제 현재 능력치를 막대로 표시합니다. 기준 미기록 안내는 유지합니다.
- 공통: 카드 여백·글자 크기·하단 메뉴·보조 버튼 대비를 통일합니다. 모바일 하단 창의 등장 이동 효과로 화면 아래가 잘리는 문제를 수정합니다.

저장 키·스키마·능력치·경기/급여/계약 계산은 변경하지 않습니다. 화면 열람에 따른 저장 데이터 불변, 320/390/800/1366px의 진행 버튼과 하단 창, 대학 진행률, 결산 실제 능력 막대, 시장 평가 열람을 회귀 검사합니다.
