# V1.9 — 시즌 보관함

KICKRU 실전 조사 4.2절의 전체 시즌 목록과 과거 시즌 재열람 흐름을 참고했다. 원본 코드·이미지·문구를 복제하지 않고, DIAMOND에 실제로 저장된 야구 기록으로 구성했다.

기록 탭의 ‘시즌 보관함’에서 완료한 프로 시즌을 선택한다. 시즌 선택 목록과 이전/다음 버튼으로 다른 시즌을 볼 수 있고, 홈 발자취와 소식의 시즌 돌아보기 버튼에서도 같은 기록을 연다. 기존 시즌별 표는 ‘표로 비교하기’에 보존한다. 대학 실전 기록은 기존 아마·선택에서 별도로 제공한다.

보고서는 해당 시즌의 소속/나이/역할, 개인 정규시즌 성적, 시즌 연봉, OVR, 기록된 세부 능력과 변화·몸 상태·성장, 팀 순위·포스트시즌 결과·수상, 국제대회 선발/메달, 보관된 경기 중 선택 및 다음 시즌 육성/계약을 구분해 표시한다. 개인 통계와 팀 포스트시즌/국제대회 결과를 합산하지 않는다.

## 저장 호환과 열람의 경계

- 저장 키와 version:1을 유지한다. 신규 완료 시즌의 career 행에 선택적 review19(version:1) 스냅샷을 추가한다. 엔진이 144경기를 마쳐 기록을 추가하는 시점에 세부 능력·집중 과제·기준값/기록시점·몸 상태·성장/선택 이력을 보관한다. 이후 성장 내역의 최근120건 제한과 다음 해의 기량/몸 상태 변화로 과거 세부 기록을 잃지 않게 한다.
- 기존 시즌은 다시 계산하거나 스냅샷을 소급 생성하지 않는다. 저장된 career 및 해당 연도의 기존 팀/수상/국제대회 기록만 읽는다. 없는 능력치·몸 상태·소속·수상 정보는 미기록으로 표시하며 현재 선수 값으로 채우지 않는다.
- 시즌 중간의 기준값과 기록 시점 불명도 구분한다. 0출장·0이닝의 비율 기록은 실적이 있는 0.00으로 오해하지 않도록 표시한다.
- 열람은 save, play, nextSeason, 결산 확인, 계약/육성 적용 함수를 호출하지 않는다. 현재 시즌을 보관함에서 보아도 비시즌 결산 확인을 대신하지 않는다. 슬롯/선수 객체가 바뀌면 열어 둔 보고서를 닫는다.

## 검증

기존51개 회귀 테스트와 신규7개: 타자/투수의 다음 해 변경 후 과거 기록 불변, 현재 결산 미확인 상태 유지, 기존 저장의 누락/잘못된 선택 필드 처리, 연도 이동 및 홈/소식 진입점, JSON 내보내기/가져오기 보존과 다른 선수 복원 시 닫기, 모바일/표/아마 기록 분리. 브라우저 테스트에서 열람 전후 커리어 객체 전체를 비교한다.
