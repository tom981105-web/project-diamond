# V1.6 — 시즌 중심 커리어 흐름

2026-10-21 KICKRU 실전 조사 문서와 `kickru-01-first-season`, `02-turning-point`, `03-contract`, `07-aging`, `10-goalkeeper` 화면에서 확인한 행동 순서를 참고했다. 원본 코드·그림·문구를 가져오지 않았으며 DIAMOND의 야구 계산과 독립적인 화면을 사용한다. 유사도 수치를 측정하거나 동일성을 보장하지 않는다.

| 조사에서 확인한 구조 | 이번 구현 |
|---|---|
| 준비 후 시즌을 보내는 주 행동 | 연도별 ‘시즌 보내기’, 1/7경기는 ‘세부 경기 관리’에 배치 |
| 중요한 시점에 선택 후 계속 | 기존 부상·복귀·1/2군·기용 선택과 남은 일정 복원 유지 |
| 개인 기록과 성장 중심 시즌 결산 | 전체 높이 보고서, 실제 타자/투수 성적·6개 능력 변화·훈련/실전 성장 내역 |
| 대회 결과·수상·시즌의 순간 | 실제 정규리그 순위·포스트시즌 우승팀·개인 수상·선택 이력 표시 |
| 결산 확인 후 다음 진로 | 결산 확인 → 육성 방향 → 계약 비교 → 다음 시즌 |
| 계약 조건을 살펴보고 확정 | V1.5의 실제 다년 계약·협상·최종 확정 유지 |

훈련 계획은 접힌 상세 영역에 있으며, 확정 중인 계획은 자동으로 펼친다. 중요한 선택과 일정 이어가기는 접히지 않는다. 이번 패치는 경기 확률, 성장 지급량, 부상 및 계약 계산식을 바꾸지 않는다. KICKRU의 진행 연출·개별 이벤트·계약 전용 모달·국가대표 시스템까지 구현한 것은 아니다. 대학 36경기와 입단 모델은 기존 야구 구조를 유지한다.

## 저장 호환

저장 키와 version:1을 유지한다. `ui13.baselineGames[year]`만 선택적 추가한다. 기준 능력치를 처음 기록한 팀 경기 수를 보관하며, 중간에 불러온 저장을 시즌 시작값으로 표시하지 않는다. 예전 기준값에 기록 시점이 없으면 알 수 없다고 표시한다. 미기록 성장 내역을 소급 생성하지 않는다. 결산 닫기는 기록이나 선택을 확정하지 않으며 확인 버튼만 reviewed를 저장한다. 육성 방향을 바꿔도 계약 선택/협상 조건은 유지하고, 효과 적용은 기존 다음 시즌 확정 시 한 번만 수행한다. 은퇴 시즌은 육성 방향을 요구하지 않는다.

## 검증

Playwright 브라우저 회귀 테스트: 대학 36경기(타자/투수)→입단→프로144경기→저장/불러오기, 슬롯·백업·저장 오류 복원, 23시즌 은퇴, 실제 성장/부상/기용/계약 계산을 포함한다. 추가 검증은 기본 상세 영역 접힘과 실제 휴식 결과, 모바일 전체 높이 결산, 닫기/재열기, 방향/계약 단계 전환과 선택 보존, 중간 저장의 기준 시점 표기를 확인한다.
