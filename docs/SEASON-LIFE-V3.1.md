# V3.1 — 시즌 중 선수 생활

시즌 화면을 현재 상황 → 훈련·회복 계획 → 일정 진행 → 완료 구간의 변화 순서로 구성했습니다. 중복된 역할·최근 구간 요약은 새 화면으로 모으고, 구간별 준비 내역과 설명은 접어 볼 수 있습니다. 기존 계획 버튼과 진행·선택 동작을 사용합니다.

현재 상황은 경기 중 선택 대기 → 라커룸 선택 대기 → 부상 → 확정한 휴식/재활 → 기본 휴식 설정 → 2군 → 몸 상태 점검 → 출전 준비 순서로 판단합니다. 남은 부상과 계획 기간, 현재 기용 역할, 집중 과제·구단 신뢰를 실제 상태에서 읽습니다. 기용 역할이 아직 없으면 평가 대기로 표시하며 출전을 보장하지 않습니다. 버튼은 실제 사건/이야기 화면 또는 훈련·휴식 계획으로 이동하며 선택을 대신 확정하지 않습니다.

최근 결과는 해당 연도의 `career14.weeks` 중 완료한 구간의 `before`와 `after`를 비교합니다. 공식 출장/등판 수는 해당 구간의 차이, 능력 변화는 여섯 능력의 전후 값, 컨디션·피로·구단 신뢰는 저장된 구간의 전후 값입니다. 당시 여러 계산의 합계이며 특정 훈련 하나의 효과라고 단정하지 않습니다. 당시 계획 종류는 `plans`에서 읽습니다. 현재 집중 과제를 과거 훈련 과제로 표시하지 않습니다.

현재 경기가 마지막 완료 구간보다 더 진행됐으면 구간 설명에 이를 표시합니다. 현재 시즌의 유효한 완료 구간이 없으면 이전 시즌 결과를 가져오지 않습니다. 대학·시즌 완료·은퇴에서는 시즌 중 화면을 숨기고 기존 대학/결산/은퇴 흐름을 유지합니다.

새 모듈은 상태를 읽고 DOM과 이동 동작만 구성합니다. 저장·난수·경기·보상·성장을 호출하지 않으며 저장 키·형식도 변경하지 않습니다. 신규 이미지는 필요하지 않습니다.

검증 범위: 새 테스트 9개와 기존 화면 구성 6개·기용/훈련/회복 8개. 현재 상황 우선순위, 실제 타자/투수 7경기 구간, 휴식의 공식 출전/성장 제외, 라커룸 선택 연결, 이전 시즌 제외, 대학/완료/은퇴, 320/390/1366px, 열람·계획 이동·새로고침의 저장 불변을 검사합니다. 전체 CI와 실제 배포 검증은 PR에 기록합니다.
