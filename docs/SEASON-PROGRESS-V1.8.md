# V1.8 — 실제 계산을 보여주는 시즌 진행

KICKRU 실전 조사 4.1절의 시즌 진행 연출·건너뛰기를 참고했다. 원본의 코드·문구·이미지를 가져오지 않았다. 대회·명단·날짜를 임의로 만들어 연출하지 않고 현재 야구 시즌의 완료 경기·기록을 표시한다.

‘시즌 보내기’와 ‘남은 일정 이어가기’는 기본 연출은 기존 경기 엔진을 최대 7팀 경기씩 실행한다. 건너뛰기와 모션 줄이기는 남은 요청 일정을 한 구간으로 계산하되 엔진의 매 경기 중요 선택 검사를 유지한다. 진행 창은 완료한 팀 경기 수, 선수 실제 출장, 타자 타율/홈런 또는 투수 ERA/탈삼진, OVR, 컨디션·피로, 소속 단계와 실제 최근 팀 경기 결과를 읽는다. 진행 단계 명칭은 완료 경기 구간에 따라 표시한다.

- 연출 건너뛰기는 화면 대기만 없애며 동일한 경기 계산을 실행한다. 중요한 선택은 건너뛰지 않는다.
- 중단·Escape는 예약 실행을 취소하고 완료한 구간과 남은 요청 일정을 보관한다. 새로고침 후 이어갈 수 있다.
- 부상·복귀·기용 변화 시 기존 엔진이 멈춘 정확한 경기에서 진행 창을 닫는다. 분할 구간이 아니라 사용자가 요청한 전체 일정의 남은 수를 유지한다.
- 시즌144경기 완료 시 기존 결산·개인상·계약 파이프라인을 한 번 실행하고 결산으로 연결한다.
- 다른 선수/연도/경기 상태로 바뀌면 예약 작업을 취소한다. 다음 선수의 커리어를 자동 진행하지 않는다.
- 계산 오류 시 해당 구간 시작 전 체크포인트로 복원하고 안내한다. 불완전한 구간의 기록을 이어서 중복 계산하지 않는다.
- 모션 줄이기 설정은 대기 없는 진행을 사용한다. 대학36경기와 1/7경기 직접 진행은 기존 동작을 유지한다.

저장 키/version:1과 경기·성장·부상·계약 공식은 유지한다. 기존 career14.remaining을 사용하며 추가 영구 필드는 없다. 창의 진행 이력과 예약 타이머는 일시적이다.

검증: 기존44개 회귀 테스트와 새7개. 실제 진행률/중단/저장 복원, 타자·투수의 연출/건너뛰기/직접 엔진 결과 동등성(동일한 난수 스트림), 부상 중단·복귀 시 남은 전체 일정, 선수 변경 후 예약 취소, 모바일·Escape·모션 줄이기, 오류 구간 복원 후 중복 없는 재개를 확인한다.
