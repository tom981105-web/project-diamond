# V3.0 — 시즌 결산과 지난 시즌의 연결

완료한 시즌의 종합 능력, 타자/투수별 핵심 성적, 결산 시 집중 과제의 실제 변화를 하나의 요약으로 보여줍니다. 기존 기준 기록 시점 안내를 유지하며, 시작 기준이 없으면 현재/보관된 값만 표시합니다. 타수와 투구 이닝이 없는 시즌의 타율/평균자책점은 `—`로 구분합니다.

팀 결과는 해당 연도의 소속·정규리그 순위·저장된 포스트시즌에서 읽습니다. 소속팀이 실제로 참가한 시리즈만 순서대로 나열하고, 팀 순서에 따른 시리즈 점수를 그대로 표시합니다. 우승은 기록된 최종 우승팀과 소속이 같을 때만 강조합니다. 진출팀 목록에 소속팀이 없을 때만 미진출 안내를 표시하고, 이전 버전의 미보관 기록은 알 수 없음으로 남깁니다.

과거 시즌 보관함도 현재 결산과 같은 성적과 팀 / 실제 성장 / 이야기와 반응 탭을 제공합니다. 키보드 좌우·Home·End 이동, 탭 상태와 패널 연결을 지원합니다. 다시보기는 이야기 탭에 있습니다. 시즌을 바꾸면 성적 탭부터 다시 보여줍니다.

지난 시즌의 역할·능력·집중 과제는 그 시즌 `review19` 스냅샷에서 읽습니다. 지금의 선수 능력이나 집중 과제로 대체하지 않습니다. 스냅샷에 역할이 없는 이전 기록은 역할별 요약을 추정하지 않고 기존 상세 기록 조회로 안내합니다. 종합 능력은 보관된 시즌 값입니다.

현재 결산의 기존 확인 버튼은 결산 확인·다음 진로(마지막 나이의 경우 은퇴 준비)로 표시합니다. 기존 확인 처리만 실행하며, 방향 선택과 계약 확정 절차를 유지합니다. 화면 구성 코드는 저장·난수·경기/성장·보상 계산을 호출하지 않습니다. 저장 키·형식·스냅샷은 변경하지 않습니다. 신규 이미지 없이 자체 UI와 기존 구단 표식을 사용했습니다.

검증: 새 결산 테스트 8개와 기존 보관함·생활/다시보기 테스트 22개. 타자·투수의 실제 완료 시즌, 다음 시즌 진입 후 이전 기록 유지, 소속팀 시리즈와 우승, 이전 저장·미기록 기준·무타수, 320/390/1366px, 키보드 탭과 저장 불변을 검사합니다. 전체 CI 및 실배포 결과는 PR에 기록합니다.
