# V2.5 — 현재 시즌과 실제 기록의 무대

홈에서 소속·연도·진행 경기를 확인하고 시즌으로 이동합니다. 대학은 실제 36경기, 프로는 실제 144팀 경기 기준이며 은퇴하면 이 진입점을 숨깁니다. 기존 사용자 제공 캐릭터를 시즌 제목 옆에 표시합니다. 부상·선택·결산 같은 중요한 단계에서는 캐릭터 장식을 숨깁니다.

시즌 진행 화면은 진행률, 실제 성과 목록, 펼쳐 보는 상세 성적·최근 경기, 화면 하단의 중지·빠른 진행 버튼으로 구성합니다. 작은 화면에서는 전체 높이를 사용하고 성과 목록 영역만 스크롤하므로 중지 버튼을 계속 사용할 수 있습니다.

성과 목록은 현재 시즌의 출장, 안타·홈런·타점·도루 또는 탈삼진·승리·세이브로 계산합니다. 각 지표에서 현재 도달한 최고 기준 하나를 표시합니다. 36/72/108팀 경기 진행 구간도 함께 표시합니다. 이는 현재 기록의 요약이며 달성 날짜·정확한 경기·최초 커리어 기록을 추정하지 않습니다. 중지 후 재개해도 현재 수치로 다시 구성합니다. 보상·추가 성장·무작위 호출·새 저장 필드가 없습니다.

기존 7경기 단위 진행, 빠른 진행의 실제 전체 계산, 부상·이야기 선택 시 일시 정지, 잔여 일정 보관과 오류 시 직전 구간 복원은 유지합니다. 저장 키와 저장 버전은 변경하지 않습니다.

검증: 기존 진행/화면 구성 13개, 새 성과·재개·저장 불변·난수 불변·320/390/1366px 조작·대학/은퇴 6개 로컬 검사 통과. 전체 CI 및 배포 검증 결과는 PR에 기록합니다.
