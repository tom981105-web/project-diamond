# V2.2 시즌 중 사건과 관계

## 진행과 저장

기존 커리어를 열거나 화면을 오가는 것만으로 새 이야기 상태를 생성하지 않습니다. 시즌 화면에서 `이야기 진행 켜기`를 직접 누르면 선택적 `narrative22`를 저장합니다. 이전 저장 키·version:1·슬롯·JSON과 실제 경기 계산은 유지합니다. 새 사건은 난수를 추가하지 않고 실제 연도·팀 경기·부상·기용·최근 성적·이전 선택에서 결정합니다.

켜는 시점의 첫 사건 이후 시즌당 최대 두 번 일정을 멈춥니다. 총 최대 세 사건, 사건 사이 최소 28팀 경기입니다. `이번에는 넘기기`는 효과 없이 다음 일정으로 이어지며, 알림을 끄면 이후 자동 정지를 사용하지 않습니다. 미해결 이야기는 부상·재활·기용의 기존 필수 선택보다 우선하지 않습니다. 시즌 종료 때 남은 선택은 만료되어 보상을 소급 적용하지 않습니다.

## 사건과 계산

- 첫 원정/추가 훈련, 이적 적응, 출전 경쟁, 실제 최근 성적의 부진, 재활, 복귀 뒤 점검, 베테랑의 후배 지도.
- 추가 훈련을 선택하면 이후 같은 동료의 영상 분석 제안이 연결됩니다. 후배를 지도하면 후배의 경기 노트가 이어집니다. 관계의 약속은 다음 시즌에도 유지되며, 이적하면 이전 구단의 약속을 초기화합니다.
- 구단 신뢰는 기존 실제 기용 평가, 팀 유대·사기는 기존 실제 경기 능력 보정을 사용합니다. 즉시 속성 성장이나 부상 기간 단축을 지급하지 않습니다.
- 훈련 선택은 실제 7팀 경기의 일반 훈련 계획을 확정합니다. 실제 훈련일과 기존 성장 체크포인트를 채워야 능력이 오릅니다. 확정된 계획·재활을 덮어쓰지 않고 남은 일정이 7경기 미만이면 훈련 선택을 차단합니다.
- 선택·넘김·만료를 각각 기록합니다. 결산·아카이브에는 실제 선택과 효과를 표시하고 팬 반응도 해당 기록을 참조합니다. 이전 시즌의 미보관 사건은 만들지 않습니다.

## 검증

열람 불변·기능 켜기/끄기, 중복 선택 차단·정확한 저장 복원, 타자/투수 실제 훈련과 후속 사건, 한 시즌 정지 횟수와 남은 일정, 기존 부상 선택 우선, 상태별 사건 분기, 결산·팬 반응·아카이브 일치, 연도·구단 전환, 320/390/1366px의 대화상자와 선수 교체 종료를 검사합니다.

## 이미지

이번 패치는 기존 사용자 제공 선수 아바타를 사용합니다. 새 필수 이미지는 없습니다. 원본 게임의 그림·문구·코드는 사용하지 않습니다.
