# V1.3 — 선수 중심 인터페이스와 시즌 선택

## 기준과 범위

기준 main은 `c3a70ac04a30dc73d2ce5b8b13c17e5968d21530`이다. 사용자가 제공한 KICKRU 실전 관찰의 핵심인 단계별 선수 생성, 선수 중심 홈, 하단 탐색, 시즌 결산 뒤 진로·계약 결정을 야구 UI에 적용했다. 원작의 로고·이미지·아바타·문구·소스는 사용하지 않았다. 시각적 유사도를 임의의 백분율로 측정하거나 전체 게임 기능이 동일하다고 주장하지 않는다.

## 실제 구현

- 4단계 생성: 독자 SVG 선수 모습6종 → 신상·출발 경로 → 타자/투수 유형 → 훈련 과제1~2개. 외형은 능력과 무관하다.
- 선수 중심 홈: 소속/나이/포지션/OVR, 프로 통산, 현재 단계의 주 행동, 건강/다음 과제, 실제 경력 타임라인.
- 5개 하단 메뉴: 홈, 소식, 시즌, 선수, 기록. 모바일과 데스크톱에서 같은 폭760px 이하의 읽기 흐름을 사용한다.
- 시즌: 대학36경기 또는 프로144경기의 실제 진행, 작은 단위 진행, 접을 수 있는 리그/최근 경기 상세.
- 시즌 종료 후 자동 결산: 원시 성적, 시즌 시작 대비 OVR, 건강 상태, 확정 수상. 이전 저장에 시작 능력치가 없으면 임의 성장치를 만들지 않는다.
- 결산 확인 → 육성 방향 선택 → 시즌 계약 선택 → 다음 시즌. 방향/계약 선택을 연도별로 저장하고, 성공한 연도 전환에서 육성 효과를 단 한 번 적용한다. 선택 기록에는 상한/하한 적용 뒤 실제 수치 변화가 남는다.
- 선수 과제: 프로12경기, 대학4경기마다 1차/2차 과제를 교대로 훈련한다. 2차가 없으면 1차에 집중한다. 합계 성장 예산은 그대로이고 이중 성장을 주지 않는다.
- 소식: 확정된 선수 기록에서 생성한 기사형 요약과 실제 이벤트. 외부 뉴스/실제 팬 반응으로 표현하지 않는다.
- 기록: 시즌 기록, 수상·이적, 아마·선택 필터. 저장 슬롯/백업/새 선수는 설정 대화상자로 이동한다.
- 기존 대학 기록은 대학 화면과 스카우팅에, 프로 기록은 프로 통산/시즌 표에 유지된다.

## 코드와 저장

`journey.js`가 기존 DOM 노드와 엔진 명령을 연결하고 `journey.css`가 새 인터페이스를 담당한다. `v61.js`는 화면 전환만 담당하도록 단순화했다. 모든 기존 필드/키/슬롯DB는 유지한다. `ui13` 확장에는 모습, 시즌 시작 능력치, 결산 확인, 연도별 임시 진로/계약 선택, 확정 진로 기록만 추가한다. 메인 스키마 `version:1`은 그대로이며 기존 프로 커리어를 대학으로 되돌리지 않는다.

PR #5의 코드/구식 index 로딩 변경은 사용하지 않았다. 방향 선택은 현재의 계약 처리 성공 후만 적용하므로 계약 거절/무효/은퇴에서 잘못 성장하지 않는다. 기존의 과거 성적/수상/이적은 다시 계산하지 않는다.

## 검증

Playwright Chromium에서 기존 커리어·슬롯·JSON·대학·프로·은퇴·경기 장면 테스트를 새 UI의 실제 버튼 경로에 맞춰 실행한다. 추가 검증은 생성4단계, 실제2개 훈련 과제의 성장, 홈 정보 우선순위, 설정 분리, 소식/시즌/선수/기록 탐색, 결산→선택→계약→다음 시즌, 선택의 재접속 복원과 중복 방지, 모바일390×844 가로 넘침/하단 메뉴, 기록 필터/접는 리그 상세다. 자동 테스트는 격리된 브라우저 저장소만 사용한다.

## 남은 범위

고교3년 직접 플레이, 아바타별 고유 외형 확장, 실제 FA 자격/다년계약, 병역/파견, 대표팀 경기/차출 선택, 세부 투구수/기용/책임주자, 다양한 은퇴 분기, 카드 내보내기는 아직 후속 과제다. 이번 릴리스는 UI/주요 결정의 연결을 바꾸며 이 기능들을 이미 완성한 것으로 표시하지 않는다. 모든 외부 공개/랭킹은 추가하지 않았다.
