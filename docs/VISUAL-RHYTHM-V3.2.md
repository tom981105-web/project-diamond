# V3.2 화면 가독성과 주요 행동

사용자가 제공한 플레이 화면의 정보 우선순위를 참고하여 PROJECT DIAMOND의 기존 캐릭터와 야구 콘텐츠로 홈·시즌 표현을 다듬었습니다. 원본 코드나 이미지 자산은 가져오지 않았습니다.

- 홈: 프로필·누적 성적·진행도·확인할 일의 글자 크기와 대비를 높이고 카드 여백을 정리했습니다. 제목은 ‘나의 야구 인생’입니다.
- 시즌: 타율 등 핵심 성적, 현재 기용 상황, 성장과 몸 상태 변화의 시각적 강약을 정리했습니다.
- 프로 시즌 진행: 스크롤 중에도 하단 메뉴 위의 고정 버튼으로 진행할 수 있습니다. 콘텐츠 아래 여백을 확보하고 대학·결산·계약 단계는 각 단계의 기존 행동을 사용합니다. 다른 탭과 대화창에서는 고정 버튼이 조작을 가리지 않습니다.
- 기존 6종 캐릭터와 동작 이미지를 사용합니다. 새 이미지는 필요하지 않습니다.

## 저장 보호

표현 CSS와 홈 제목, 캐시 버전만 변경했습니다. 저장 키·형식·마이그레이션·난수·경기·성장·훈련·부상·계약 계산은 변경하지 않습니다.

## 검증

`tests/visual-rhythm.spec.js`는 320·390·800·1366px에서 긴 선수 이름, 최소 글자 크기, 진행 버튼과 하단 메뉴 사이 간격, 스크롤 후 버튼 위치, 대화창 접근, 다른 탭의 버튼 숨김, 상태와 저장 원문 불변을 검사합니다. 대학·결산 단계의 진행 버튼도 확인합니다. 기존 생성·대학 36경기·프로 진입·시즌·저장 회귀 테스트를 함께 실행합니다.
